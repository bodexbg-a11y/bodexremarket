# BODEX Bulgaria — полуремаркета

Български продуктов лендинг за гамата полуремаркета и транспортни решения BODEX.

## Локално стартиране

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run build
npm run lint
```

## Vercel

Проектът използва стандартен Next.js и не изисква специална конфигурация.
Импортирайте GitHub репозитория във Vercel; Framework Preset се разпознава
автоматично като **Next.js**, а build командата е `npm run build`.

Продуктовите категории, техническите данни и снимките са адаптирани от официалния каталог на производителя: https://www.bodex.com.pl/produkty-3
