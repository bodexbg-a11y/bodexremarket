# BODEX Bulgaria — полуремаркета

Български продуктов лендинг за гамата полуремаркета и транспортни решения BODEX.

## Локално стартиране

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run build
npm run lint
```

Продуктовите категории, техническите данни и снимките са адаптирани от официалния каталог на производителя: https://www.bodex.com.pl/produkty-3
